Поиск и проверка платежа по уникальному коду
 
json xml
URL для передачи запроса:
https://api.digiseller.com/api/purchases/unique-code/{unique-code}?token={token} - основной адрес

https://oplata.info/api/purchases/unique-code/{unique-code}?token={token} - резервный адрес
Метод:
GET
Заголовки запроса:
Accept: application/json
Параметры запроса:
Название	Назначение	Примечание
unique_code	уникальный 16-тизначный код, который покупатель получает после оплаты	строка из 16-ти символов
token	токен доступа,
мин. разрешение: [ Операции ]: Детали счета	метод создания токена доступа
Формат ответа:

пример JSON-ответа	
{
  "retval": 0,
  "retdesc": "",
  "inv": 0,
  "id_goods": 0,
  "amount": 0.0,
  "type_curr": "",
  "profit": "",
  "amount_usd": 0.0,
  "date_pay": "",
  "email": "",
  "agent_id": 0,
  "agent_percent": 0,
  "unit_goods": 0,
  "cnt_goods": 0,
  "promo_code": "",
  "bonus_code": "",
  "cart_uid": "",
  "unique_code_state": {
    "state": 0,
    "date_check": "",
    "date_delivery": "",
    "date_confirmed": "",
    "date_refuted": ""
  },
  "options":[
    {"id": 0, "name": "", "value": "", "variant_id": 0},
    {"id": 0, "name": "", "value": "", "variant_id": null}
    ...
  ]
}
параметры ответа:
название	назначение	примечание
retval	код выполнения запроса	0 - запрос выполнен
retdesc	расшифровка кода выполнения запроса	
inv	уникальный номер оплаченного счёта в системе учета Digiseller
настоятельно рекомендуем сохранять это значение в базе и каждый раз проверять его на уникальность, чтобы избежать двойных начислений
целое число
id_goods	идентификатор оплаченного товара	целое число
amount	сумма, зачисленная на ваш счет	
type_curr	валюта платежа, зачисленного на ваш счет (не способ платежа!)	WMZ | WMR | WME | WMX
amount_usd	сумма платежа в USD	
profit	сумма, зачисленная на ваш счет (за вычетом комиссий)	
date_pay	дата и время заказа	
email	email покупателя	
name_invoice	наименование счета	
lang	языковая принадлежность покупателя	
agent_id	ID партнера, если продажа была совершена с участием партнера	
agent_percent	процент партнерского вознаграждения	
query_string	base64-закодированная строка, содержащая набор параметров, дополнительно переданных с вашего сайта на страницу оплаты oplata.info. Параметры могут нести в себе User ID, значения для отслеживания конверсии оплаты и т.п.
После base64_decode, строка будет выглядеть примерно так: "param1=value1&param2=value2&..."	
пример:
bWVtYmVyX2lkPTIzNDE2NTQ0JnNvdXJjZT1yZWd1bGFyJmxheW91dF9pZD0xNSZnYV9jbGllbnRfaWQ9MjI2ODYyNDMyLjE0NjY2Njg5ODkmZm9ybV9pZD03

После base64_decode:
member_id=23416544&source=regular&layout_id=15&ga_client_id=226862432.1466668989&form_id=7
unit_goods	единица оплаченного товара	только для товаров с нефиксированной ценой
cnt_goods	количество единиц оплаченного товара
обязательно проверяйте это значение!
только для товаров с нефиксированной ценой
promo_code	промо-код, использованный покупателем при оплате	только если при оплате был использован промо-код
bonus_code	промо-код, выданный покупателю в виде бонуса после оплаты	только если после оплате был выдан промо-код
cart_uid	UID корзины	только если товар был добавлен и оплачен через корзину
unique_code_state	уникальный код (состояние и даты проверки)	необязательное поле
unique_code_state\state	состояние сделки	число, возможные значения:
1 - уникальный код не проверен
2 - товар доставлен, доставка не подтверждена и не опровергнута
3 - товар доставлен, доставка подтверждена
4 - товар доставлен, но отвергнут
5 - уникальный код проверен, товар не доставлен
unique_code_state\date_check	дата проверки	строка. необязательное поле
unique_code_state\date_delivery	дата доставки	строка. необязательное поле
unique_code_state\date_confirmed	дата подтверждения	строка. необязательное поле
unique_code_state\date_refuted	дата отказа	строка. необязательное поле
options	список параметров	только для товаров с доп. параметрами
options\option	параметр, который выбрал или указал покупатель	атрибут id - уникальный идентификатор параметра
options\option\name	название параметра	
options\option\value	значение параметра, выбранное или указанное покупателем	
options\option\variant_id	ID варианта параметра, согласно выбору покупателя	целое число. может быть пустым (только для полей 'radio' и 'select')
