---
name: Digiseller buyer chat promotions
description: Operational rule for the one-time promo codes sent through Digiseller buyer chats.
---

One-time promo codes sent after delivery are valid for 30 days and are redeemed atomically when the buyer sends the code in a later Digiseller order chat. The system confirms registration, but the 5% discount is applied manually by an operator.

**Why:** The documented Digiseller API supports buyer correspondence but does not provide a confirmed endpoint for creating and automatically applying custom one-time checkout coupons. Claiming automatic application would be misleading.

**How to apply:** Keep customer-facing copy explicit about manual application. Do not change this to automatic checkout discounting without first confirming and testing an official Digiseller mechanism.
